# E-commerce-Book-Store
Developed a dynamic bookstore web application as part of a second-year Database and Web Development project. As the Full Stack Developer, I designed and implemented both the front-end and back-end systems using PHP, HTML, CSS, JavaScript, and MySQL (via phpMyAdmin). The platform allows users to easily browse available books and purchase them through an intuitive interface. I also built a secure admin dashboard that enables the store owner to manage book listings, update inventory, and oversee store operations efficiently. This project strengthened my skills in web development, database management, and system design, while demonstrating my ability to build complete, functional web applications.
